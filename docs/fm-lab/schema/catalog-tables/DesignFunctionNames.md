# DesignFunctionNames

Part of the [FM-Lab schema](../Schema.md) · Calculations & variables · `db/fm_catalog.duckdb` (solution catalog)
**Source:** the generated seed `ingestion/sql/generated/design_functions_seed.sql`, derived from the [fm-spec](../../Wiki/fm-spec.md) reference database by `ingestion/gen_design_functions.sh` — not extracted from the XML export

The names of FileMaker's **design functions** (`BaseTableIDs` … `WindowNames`, 23 functions) in every reference language. It is the positive match list of the pipeline's phase 1c: FileMaker's export tags design functions as `PluginFunctionRef` chunks in the language of the client that wrote the formula, and the importer re-types exactly the chunks whose token appears here (see [DDR_Calculations](DDR_Calculations.md)). Solution-independent; rebuilt on every import from the seed shipped with the engine.

## Columns

| Column | Type |
|---|---|
| `Function_ID` | `INTEGER` |
| `Canonical_Name` | `VARCHAR` |
| `Language` | `VARCHAR` |
| `Name` | `VARCHAR` |
| `Name_XML` | `VARCHAR` |

## Notes

- `Function_ID` and `Canonical_Name` are the reference identity of the function (`functions.function_id`, English name); `Language` is the reference language code of the spelling, or `lookup:<source>` for an extra spelling known only to the reference's name lookup.
- `Name` is the spelling as FileMaker writes it into a calculation (`Fensternamen`, `WindowNames`, `Nomsfenêtres`, …). Matching is case-insensitive.
- `Name_XML` holds the same spelling with every non-ASCII character as an XML numeric character reference (`WertelisteEintr&#xE4;ge`) — the form the DOM chunk path serializes into `DDR_Calculations.Chunk_Content`; `NULL` when identical to `Name`.
- The seed carries its provenance (reference schema version, source commit, build time) in its header and is regenerated by `tools/fm-reference/pull-reference.sh` after every reference deploy; `ingestion/gen_design_functions.sh --check` is the freshness gate.
- Not an object catalog: the table never joins into [ObjectCatalog](../object-catalog/ObjectCatalog.md) or [ObjectLinks](../object-catalog/ObjectLinks.md). The re-typed functions register as `BuiltinFunction` objects (see [Object Types](../object-catalog/Object%20Types.md)).
