FM-Lab is built on **[open-source software](Dependencies.md)** and contributes to the open-source ecosystem itself.

A main goal — and an important driver behind the development of FM-Lab — is to support the **FileMaker community**:
- Support FileMaker developers in their daily workflows.
- Help sustain and maintain existing FileMaker projects.
- Preserve FileMaker best practices and community knowledge for future generations of developers.

The FileMaker open-source ecosystem has grown and matured over many years. Besides FM-Lab, there are many notable projects that contribute to **preserving and sharing community wisdom** and **providing useful tools** for everyday development work.

This page highlights a selection of open-source projects that complement FM-Lab or address related areas. It is not intended to be a complete directory:

### FileMaker XML Tools

**FileMaker XML-Export File Exploder**  
[fm-xml-export-exploder](https://github.com/bc-m/fm-xml-export-exploder) – FileMaker XML-Export File Exploder is a fast Rust tool designed to parse XML files exported from FileMaker databases and extract relevant content into separate files.  
MIT License – Copyright © 2024 Malte Bastian  

**fmCheckMate-XSLT**  
[fmCheckMate-XSLT Library](https://github.com/mrwatson-de/fmCheckMate-XSLT) – The fmCheckMate-XSLT Library is a whole bunch of XSL transformations and other functions to transform your FileMaker work … into something very much better!  
MIT License – Copyright © 2018 Russell Watson  
➡️ Some of the included Stylesheets have inspired the [SCA Rules](Static%20Code%20Analysis.md) of FM-Lab

**patchlab**  
[patchlab](https://github.com/soliantconsulting/patchlab) – This tool helps FileMaker developers explore the Save-as-XML (SaXML) format and work with the FMUpgradeTool to build, test, and organize patch files.  
MIT License – Copyright © 2025 Soliant Consulting

**fm xml download**  
[fm-saxml-delivery](https://github.com/soliantconsulting/fm-saxml-delivery) – This is intended to download a filemaker SaXML out of a container that is generated by script into a folder called SaXML.  
MIT License – Copyright © 2024 Soliant Consulting

**Clockwork Inspector for FileMaker**  
[FileMaker-XML-inspector-open-source](https://github.com/andykear/FileMaker-XML-inspector-open-source) – Full-solution analysis for FileMaker. Local, in the browser, open. No install, no licence, no cloud.  
CC BY 4.0 License – Copyright © 2026 Andrew Kear

**BaseElements-DDR-XSLT**  
[BaseElements-DDR-XSLT](https://github.com/GoyaPtyLtd/BaseElements-DDR-XSLT) – All of the BaseElements XSLT files that we use internally to pull data out of the FileMaker Pro Advanced XML DDR.  
GPL-3.0 License – Copyright © 2018 Nicholas Orr
