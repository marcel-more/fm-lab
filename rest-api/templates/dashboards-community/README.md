# Community dashboards

Reserved for dashboard bundles shared by the fm-lab community. The area ships
empty; once it holds bundles they appear in the dashboard overview under
**Community**.

The same layout rules as for `../dashboards-custom/` apply: the bundle
directory name equals `manifest.id`, and sub-folders (optionally with a
`folder.json`) group related bundles. A community bundle never overrides an
existing dashboard id — on a collision it is ignored.
