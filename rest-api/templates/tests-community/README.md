# Community Analysis Tests

Reserved for Analysis Tests shared by the fm-lab community. The area ships
empty; installed community packages place their tests here, and they appear in
the test overview under **Community**.

The same layout rules as for `../tests-custom/` apply: a test is a directory
named after its id with a `test.json`, and sub-folders (optionally with a
`folder.json`) group related tests. A community test never overrides an
existing test id — on a collision it is ignored.
